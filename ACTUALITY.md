# Насколько актуальны собираемые данные

Исследование от 25.09.2026. Живые сайты с машины разработки недоступны (геоблок), поэтому использованы архивные снимки Web Archive:
- список врачей УЗИ napopravku, Казань, 12.2025;
- 48 профилей врачей УЗИ napopravku 2026 года: Ростов, Воронеж, Волгоград, Краснодар, Ставрополь, Пятигорск плюс Москва, Екатеринбург, Новосибирск, Казань;
- 47 профилей врачей prodoctorov, Ростов-на-Дону, 2022–2023 (разные специальности; позже архив к сайту не пускают);
- список prodoctorov, Казань, 2021.

## Коротко
- **Данные «живые» по времени загрузки**: каждая строка собрана с сайта в момент сессии, кэша нет, в Excel попадает только текущая сессия.
- **Фактическая актуальность упирается в сам сайт.** Парсер не может знать больше, чем сайт. По выборке **≈80–90 % строк надёжно подтверждены**, **≈10–20 % под риском устаревания**: врач числится в клинике, но признаков активности давно нет.
- Сайты сами не выводят «не принимает» в списках: napopravku вообще не показывает врачей без клиники, у prodoctorov у таких врачей просто нет клиник. Поэтому текстовые маркеры почти ничего не отсеивают. Основной фильтр — наличие текущей клиники.

## Что показали данные

### napopravku (48 профилей, 20 карточек списка)
| Признак | Доля | Что значит |
|---|---|---|
| Врач без места работы | 0 % | сайт таких не показывает, фильтр по клинике ничего не отсекает |
| Онлайн-запись через МИС клиники (`rtaId`, `analyticType: rtbooking`) | 43 % | расписание синхронизируется с системой клиники: самый надёжный признак |
| Только «обычные» клиники (`regular`) | 57 % | данные ведутся вручную, могут отставать |
| └ из них последний отзыв старше 2 лет | 8 из 25 (≈32 %) | **≈17 % всех строк napopravku под риском** |
| У врачей с МИС последний отзыв старше 2 лет | 0 из 19 | медиана давности отзыва 100 дней |
| Поле `recentlyUpdated` | всегда = дата отдачи страницы | как признак свежести **бесполезно** |

Пример из выборки: женская консультация, клиника не партнёр, последний отзыв в 08.2023, а в 2026 году врач всё ещё в списке. Текущие критерии считают его актуальным.

### prodoctorov (47 профилей, Ростов)
| Признак | Доля |
|---|---|
| Нет текущих клиник | 4 % (2 из 47): **наш фильтр их отсеивает** |
| Есть клиника, но последний отзыв ≥ 3 лет до даты снимка | ≈8 % (4 из 47): риск |
| Последний отзыв в год снимка или годом раньше | 83 % |

На первой странице списка (Казань) у всех 20 врачей есть клиники. Слоты расписания грузятся JavaScript'ом, в HTML их нет.

## Найденная и исправленная ошибка
Маркеры «не принимает» / «больше не» / «не работает» искались по всему тексту карточки, включая отзывы («жаль, что **не принимает** детей», «такого врача **больше нет**»). В 14 из 47 профилей prodoctorov такие фразы были **только в отзывах**. Это грозило ошибочным отсевом работающих врачей. Исправлено: отзывы исключаются из проверки (`statusText`), добавлен тест.

## Ограничения исследования
- Выборки небольшие (≈50 на источник), погрешность порядка ±10 п.п.
- Архив хранит в основном популярные профили, а у малоизвестных врачей устаревание, вероятно, выше.
- Дата последнего отзыва — косвенный признак: у работающего врача может просто не быть отзывов.
- Разметка prodoctorov 2026 года не проверена (сайт закрыт антиботом и для архива).

## Рекомендации (по убыванию пользы/затрат)
1. **Уровень актуальности в выгрузке вместо «да/нет»**, без лишних запросов. У napopravku скрытый JSON списка (`__INITIAL_STATE__`) уже содержит `rtaId`, `analyticType`, `isPremium`:
   - **A** — онлайн-запись через МИС клиники;
   - **B** — клиника-партнёр;
   - **C** — обычная клиника без подтверждения.
2. **Глубокая проверка для уровня C** (опция): открыть профиль, взять дату последнего отзыва; старше 2 лет → «требует проверки». Это +1 запрос на такого врача, примерно +3–5 минут на 2000 врачей.
3. **Слоты расписания в режиме браузера**: дождаться их подгрузки на prodoctorov. «Есть свободные слоты» — самый сильный признак.
4. **Подтверждение двумя источниками**: врач с той же клиникой на обоих сайтах получает повышенный уровень.
5. Для заказчика: колонки «Уровень актуальности» и «Основание» в Excel, чтобы было видно, на чём основана уверенность.
