# УЗИ-парсер

Собирает **актуальных** врачей ультразвуковой диагностики по городу или области с napopravku.ru, prodoctorov.ru и zoon.ru. Дубли между сайтами склеиваются (ФИО без учёта порядка слов и «ё» + город). Каждый врач записывается одной строкой в SQLite и в Excel: `ФИО — Должность; сфера работы; место работы`.

Стек: Go (парсер и API) · React + Vite (UI) · Tauri v2 (десктоп-оболочка) · SQLite + XLSX (данные для заказчика).
План: [PLAN.md](PLAN.md). Ход работ: [STATUS.md](STATUS.md).

## Требования
- **Российский IP-адрес (VPN выключен).** Медицинские сайты не отвечают зарубежным адресам: TLS-соединение зависает.
- Google Chrome (нужен для prodoctorov, который закрыт антиботом).
- Для сборки: Go 1.23+, Node 20+, Rust (только для Tauri).

## Запуск
| Что | Команда |
|---|---|
| Десктоп-приложение | `./scripts/build.sh`, затем открыть `src-tauri/target/release/bundle/macos/UZI Parser.app` |
| Без Tauri, в браузере | `./scripts/run.sh` → http://127.0.0.1:8765 |
| Разработка (hot reload) | `./scripts/dev.sh` → http://localhost:5173 |
| Все проверки | `./scripts/test.sh` (+ `cd backend && go test -tags integration ./internal/fetch/` — реальный Chrome) |

## Как пользоваться
1. Выберите цель (есть поиск):
   - **★ Готовый набор**: «Ростов и соседние регионы» (Ростовская обл., Краснодарский и Ставропольский края, Волгоградская и Воронежская обл., Калмыкия; 65 городов) или «Ростовская агломерация» (Ростов, Батайск, Аксай, Азов, Новочеркасск). Набор Ростова выбран по умолчанию;
   - один город или «▸ Вся область»;
   - **несколько целей**: выбирайте по одной и нажимайте «+ В список». Всё из списка соберётся за одну сессию, повторы городов уберутся;
   - **ближайшие области вручную**: выберите регион или город, и под списком появятся граничащие с ним области. Отметьте нужные галочками. Кнопка «показать второй круг» открывает соседей соседей. Строка «Будет собрано: N рег., M гор.» пересчитывается сразу. Соседство регионов хранится в `backend/internal/geo/neighbors.txt`;
   - **ближайшие города**: если выбран город, сверху показываются города в радиусе 25, 50, 100 или 150 км (например, для Ростова-на-Дону: Батайск 10 км, Аксай 13, Азов 25, Новочеркасск 36). Нужные отмечаются галочками или кнопкой «все в радиусе».
2. Нажмите **Начать**. Время сессии, счётчик врачей, страницы и скорость обновляются вживую.
3. Галочка «+ функциональная диагностика (УЗДГ, ЭхоКГ)» добавляет врачей функциональной диагностики со всех трёх сайтов. По умолчанию выключена: часть таких врачей делает только ЭКГ и ЭЭГ. В Excel их видно по колонке «Должность».
4. Если сайт покажет капчу, появится жёлтый баннер. Решите капчу в окне Chrome, и сбор продолжится сам. Cookies сохраняются в профиле, поэтому повторно капча обычно не нужна.
5. **Закончить** (или окончание обхода) → данные в БД, Excel создаётся автоматически. Кнопка «Показать в папке» открывает файл в Finder.

Данные лежат в `~/Documents/UZI-Parser/`:
- `uzi_doctors.db` — SQLite: таблицы `doctors` (уникальность по ФИО + город) и `sessions`;
- `exports/УЗИ_<цель>_<дата>.xlsx` — лист «Врачи УЗИ» и лист «Сессия» с критериями;
- `chrome-profile/` — профиль браузера парсера.

## Что считается «актуальным»
- Данные загружаются в момент сессии, с `Cache-Control: no-cache`. У каждой записи есть `checked_at`.
- У врача есть текущее место приёма и запись или телефон. Карточки с пометками «не принимает», «больше не работает» и т. п. отсеиваются (счётчик «Отсеяно»).
- В Excel попадают только врачи, подтверждённые **в этой сессии**. Старые записи из прошлых запусков в документ не выгружаются.

## Скорость
- Режим «Авто»: napopravku (6 потоков) и zoon (4 потока) идут через HTTP-пул. Если сайт отдаёт пустую JS-заглушку, источник сам переключается на браузер. Когда prodoctorov отвечает антиботом, он автоматически переключается на Chrome (4 вкладки, без картинок, шрифтов и счётчиков).
- Первая страница города сообщает число страниц, остальные загружаются параллельно. Дубли из двух источников объединяются.
- Стенд (`engine_test.go`): 2400 врачей на 149 страницах обрабатываются примерно за 2 с. На живых сайтах скорость ограничивает сам сайт.

## Как дорабатывать
- **Изменилась разметка сайта**: положите `~/Documents/UZI-Parser/selectors.json`, пересборка не нужна:
  ```json
  { "napopravku": { "card": ".new-card" }, "prodoctorov": { "spec": ".new-spec" } }
  ```
  Ключи есть в `napopravkuDefaults` / `prodoctorovDefaults` ([backend/internal/sources](backend/internal/sources)). Если на странице 0 карточек, об этом появится сообщение в журнале.
- **Новые города**: [backend/internal/geo/cities.txt](backend/internal/geo/cities.txt), формат `Регион|Город|slug prodoctorov|slug napopravku|slug zoon`. У zoon отдельные разделы есть только у крупных городов.
- **Новые наборы**: [backend/internal/geo/presets.txt](backend/internal/geo/presets.txt), формат `Название|region:…;city:…`. Опечатка в цели будет поймана при запуске и в тестах.
- **Новый источник**: реализуйте интерфейс `sources.Source` (`ListURL`, `Parse`, `Concurrency`) и добавьте его в `sources.All()`.
- API: `GET /api/regions`, `POST /api/start {target, mode, showBrowser}`, `POST /api/stop`, `GET /api/status`, `POST /api/export`, `GET /api/export.xlsx?session=N`.

## Известные ограничения стенда
- Живой обход не проверялся с машины разработки: сайты недоступны из-за геоблока. Парсеры проверены тестами на реальных HTML-снимках: napopravku от 12.2025, prodoctorov 2021–22. Разметку prodoctorov 2026 года стоит сверить при первом запуске.
- В окне Tauri кнопка «Скачать Excel» может не сработать (WebView не всегда поддерживает загрузки). Используйте «Показать в папке»: файл уже сохранён на диск.
- Сборка настроена под macOS (`.app`). Для Windows/Linux поменяйте `bundle.targets` в [src-tauri/tauri.conf.json](src-tauri/tauri.conf.json).

## Данные и лицензии
Координаты городов (`backend/internal/geo/coords.txt`) взяты из справочника [hflabs/city](https://github.com/hflabs/city) (лицензия CC BY-SA 4.0) и дополнены вручную для станиц, ДНР и ЛНР.
Если врач с полным ФИО найден в нескольких городах одного региона, он записывается одной строкой, а в колонке «Город» перечисляются все города.
